# 灌装线欠重累计复检 + 留样台账条码配对

## 复检

灌装线每次少装几克，连续下来就要复检。上传「抽检序号 + 整数克重」CSV 存入
SQLite，按序号顺序把 **(499 − 实测克重)** 计入累计，累计 **< 0 归零**；累计 **≥ 20 克**
时记录一条复检事件（本轮累计转正起点序号 → 触发序号、累计克数），随后清零。

## 留样台账

留样台账只记条码和克重，质检员要凭抽检序号找到留样袋。在首页**从已有抽检序号中
选一段**（区间内称重最多 **200 条**），导入按留样顺序排列的「条码,整数克重」CSV
建一份台账，系统按当前称重自动配对：

- 条码不能重复；按台账顺序对应**递增的不同抽检序号**；台账克重与称重**最多差 1 克**；
  未留样的称重可以跳过；
- **配不齐**整份台账时页面给出提示（并标出无可配序号的行）；
- 存在**多种完整配对**时，页面标出**有歧义的条码**及其候选序号；
- 质检员可**登记/撤销现场核实**（条码 ↔ 序号）。已核实的条码固定到核实序号
  （不再受克重差约束）；若新核实与已有记录一起配不齐整张台账，本次登记被退回；
- 整份台账**只有一种配对**时才可**发布**，且提交配对须与页面所见一致
  （期间称重或核实有变动则发布被拒，需刷新页面）；
- 发布后可在台账页**按序号查条码**；
- **称重更正照常生效**。更正或撤销核实一旦让原配对不再是唯一解，**同次操作即暂停
  查袋**；旧配对保留在「发布记录」中供追查，**恢复查袋须重新发布**。

## 运行

```bash
docker compose up --build        # 打开 http://localhost:5000
```

数据保存在名为 `filling-data` 的卷里（容器内 `/data/filling.db`），重启、失败后不丢。
不用 Docker 也可以本地跑：

```bash
pip install -r requirements.txt
python app.py                    # 默认 ./filling.db，可用 FILLING_DB 指定路径
```

## CSV 格式

**称重 CSV** 两列：`抽检序号,整数克重`，首行表头可省。可上传文件或在网页上粘贴。

- **同号可更正**：已存在的序号再次上传即覆盖克重并触发复算；
- **新号只往后追加**：新序号必须大于当前最大序号，否则整批拒绝；
- 文件内序号不得重复；序号、克重必须为非负整数（序号 ≥ 1）。

**台账 CSV** 两列：`条码,整数克重`，按留样顺序排列，首行表头可省。

- 条码在文件内不得重复，最长 64 字符，不得含空白与 `, : ;`；
- 克重为非负整数；一份台账最多 200 行。

## 复算策略（增量）

每次上传一个事务，重量与复检清单一同生效：

1. **跳过首处改动前的称重**：从首个改动序号起算，改动前的累计值/本轮起点直接取
   `run_state` 中保存的状态；
2. **汇合即沿用**：复算途中若已越过全部更正、当前序号仍是旧数据，且（累计值， 本轮起点）
   与旧结果一致，则之后的旧状态与旧复检事件原样保留，不再重读重量；
3. 若旧末尾之后还有本次新增的序号，则从旧末尾状态继续处理新增部分。

每批次的复算起点（`first_changed`）与沿用点（`resumed_at`）记录在 `batches` 表，
网页「批次记录」可见。

## 配对判定（台账）

设区间称重为 `seq[1..m]`、台账行为 `row[1..n]`。用两个前缀/后缀动态规划：

- `L[i][j]`：前 i 行台账能否配进前 j 条称重；
- `R[i][j]`：第 i 行起的台账能否配进第 j 条起的称重。

第 i 行可配序号 j 当且仅当相容（克重差 ≤ 1，或已被核实到该序号）且 `L[i][j]` 与
`R[i+1][j+1]` 均成立。每行候选序号恰有一个 ⟺ 完整配对唯一；候选多于一个的行即
歧义行。m、n 均不超过 200，计算量可忽略。

## 并发与持久化

- 进程内全局锁 + `BEGIN IMMEDIATE` 写事务：并发上传与台账变更按生效顺序串行处理；
- 每批/每次变更要么整体生效要么整体回滚，失败不影响最近一次成功结果；
- 更正触发的台账停查与称重更正在**同一事务**内生效；
- SQLite（WAL）落盘，重启后最近一次成功结果仍可查。

## 接口

| 方法/路径 | 说明 |
| --- | --- |
| `GET /` | 网页：复检清单、最近称重、批次记录、台账列表与新建台账表单 |
| `POST /upload` | 表单上传称重 CSV（文件或粘贴文本） |
| `GET /ledger/<id>` | 台账页：配对分析、现场核实、发布、按序号查条码、发布记录 |
| `POST /ledger/new` | 表单建台账（序号区间 + 台账 CSV） |
| `POST /ledger/<id>/verify` | 登记现场核实（条码、序号） |
| `POST /ledger/<id>/unverify` | 撤销现场核实 |
| `POST /ledger/<id>/publish` | 发布（隐藏域携带页面所见配对） |
| `POST /api/upload` | 称重 CSV 正文上传，返回 JSON |
| `GET /api/state` | 当前累计、本轮起点、最近序号、计数 |
| `GET /api/events` | 复检清单（按触发序号排序） |
| `GET /api/weighings?limit=` | 称重记录 |
| `POST /api/ledgers` | 建台账 `{start_seq, end_seq, csv}` |
| `GET /api/ledgers/<id>` | 台账分析 JSON（候选、歧义、唯一解、核实、发布记录） |
| `POST /api/ledgers/<id>/verify` | 登记核实 `{barcode, seq}` |
| `POST /api/ledgers/<id>/unverify` | 撤销核实 `{barcode}` |
| `POST /api/ledgers/<id>/publish` | 发布 `{pairs: [[条码,序号],...]}` |
| `GET /api/ledgers/<id>/lookup?seq=` | 按序号查条码（未发布/已暂停返回 409） |
| `GET /healthz` | 健康检查 |
